## Hero video files

Drop your hero video in this folder using one of these filenames:

- `hero.webm` (recommended for size/quality)
- `hero.mp4` (fallback)

The Home page will automatically use them as:

- a background video in the hero section
- a modal video when you click **Watch Video**

Tips:

- Keep it short (5–12 seconds) and loop-friendly.
- Export at 1080p, 24–30fps, and aim for a small file size for fast loading.
